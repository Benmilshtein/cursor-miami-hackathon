# Cursor Miami Ship Night

One-night open AI ship night in Miami. Every level welcome.

Rules for authenticity review:
- Event window is defined by T0/T1 in config.json (doors/build/demos).
- Prefer evidence of work during the event window.
- Pre-T0 commits are a review flag, not automatic disqualification.
- Bulk dumps and huge initial commits after T0 deserve a closer look.
- Reward beginners for progress in one night; reward usefulness and a working public demo URL.
